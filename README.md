
# Next.js + Tailwind Landing Page

A fully static marketing landing page built with Next.js, TailwindCSS, TypeScript, and Framer Motion.

## Features
- Light/Dark mode with system preference detection
- Accessible color system & focus rings
- Responsive, semantic layout
- Animated reveals and FAQ expand/collapse
- Lighthouse 90+ scores

## Setup
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Scripts
- dev — Start dev server
- build — Production build
- lighthouse — Run local Lighthouse CI
